# The use of strong passwords is very important in Cybersecurity. A strong password is the first line of defence.

## This script checks the strength of passwords by following the rules given below:
•   Minimum length of 12 characters

•   Contains at least one uppercase letter

•   Contains at least one lowercase letter

•   Contains at least one digit

•   Contains at least one special character

## To test the script, use the following steps:
• 	Copy the Python code and save it using a suitable file name,
    "password_checker.py"
    
•   Open a terminal or command prompt

•   Navigate to the folder where you saved the file

•   Run:
    "python3 password_checker.py"
    Check the Output
    
•   The script prints whether each password passes or fails, along with the reason.
